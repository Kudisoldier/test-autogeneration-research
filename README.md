# Feedback Form Application

Simple one-page React app with Express backend for submitting feedback.

## Quick Start

```bash
# Install dependencies
make install

# Start development servers (frontend + backend)
make dev
```

App will be available at:
- Frontend: http://localhost:3000
- Backend: http://localhost:3001

## Makefile Commands

- `make install` - Install all dependencies
- `make dev` - Start both frontend and backend
- `make server` - Start backend only
- `make client` - Start frontend only
- `make build` - Build for production

## API

**POST /api/feedback** - Submit feedback
```json
{
  "name": "John Doe",
  "email": "john@example.com",
  "rating": 5,
  "message": "Great service!"
}
```

## Features

- Form validation (client & server)
- All elements have `data-testid` attributes for testing
- Responsive design
- Comprehensive test suite (Unit, Integration, E2E)

## Research Purpose

This application is set up as a **base for research** on comparing different LLMs and approaches for autogeneration of autotests for web applications.

**Note**: No tests are pre-written. The infrastructure is configured, but test files should be generated by different LLMs/approaches for comparison.

### 🚀 Test Generation with OpenRouter

Generate tests using different LLM models via OpenRouter API.

#### Commands (scripts)

```bash
# Generate one test file (single model + single target)
npm run generate:test -- --model <model> --type <unit|integration|e2e> --target <target>

# Generate tests for ALL targets of a type AND for MANY models (hardcoded list by default)
npm run generate:all -- --type <unit|integration|e2e>
```

You can also run the generator directly:

```bash
node scripts/generate-tests.js --help
```

#### Supported test types, targets, and generated filenames

Generated files are saved to:

`research-output/<model>/<type>/<filename>`

Where `<filename>` is the basename of the target file below:

```text
unit:
  FeedbackForm    -> client/src/components/__tests__/FeedbackForm.test.jsx  (filename: FeedbackForm.test.jsx)
  FeedbackList    -> client/src/components/__tests__/FeedbackList.test.jsx  (filename: FeedbackList.test.jsx)
  validation      -> client/src/utils/__tests__/validation.test.js          (filename: validation.test.js)

integration:
  api             -> server/__tests__/api.test.js                           (filename: api.test.js)
  validation      -> server/utils/__tests__/validation.test.js              (filename: validation.test.js)

e2e:
  feedback-form   -> tests/e2e/feedback-form.spec.js                        (filename: feedback-form.spec.js)
```

#### Generate ONE specific test file

```bash
# Unit: FeedbackForm
npm run generate:test -- --model openai/gpt-5.2-codex --type unit --target FeedbackForm

# Integration: API
npm run generate:test -- --model openai/gpt-5.2-codex --type integration --target api

# E2E: feedback form flow
npm run generate:test -- --model openai/gpt-5.2-codex --type e2e --target feedback-form

---

# Unit: FeedbackList
npm run generate:test -- --model llama-3.1-8b-free --type unit --target FeedbackList

# Unit: validation utils
npm run generate:test -- --model llama-3.1-8b-free --type unit --target validation

# Integration: server validation
npm run generate:test -- --model llama-3.1-8b-free --type integration --target validation
```

#### Generate ALL targets for a type (for many models)

```bash
# All unit targets (FeedbackForm, FeedbackList, validation) for each model in the built-in list
npm run generate:all -- --type unit

# All integration targets (api, validation) for each model in the built-in list
npm run generate:all -- --type integration

# All e2e targets (feedback-form) for each model in the built-in list
npm run generate:all -- --type e2e
```

#### Generator options

```bash
# Custom output directory (default: research-output/)
npm run generate:test -- --model llama-3.1-8b-free --type unit --target FeedbackForm --output-dir research-output

# Temperature (default: 0.7)
npm run generate:test -- --model llama-3.1-8b-free --type unit --target FeedbackForm --temperature 0.5

# Max tokens (default: 8000)
npm run generate:test -- --model llama-3.1-8b-free --type unit --target FeedbackForm --max-tokens 12000
```

`--use-api-models` and `--free-only` are intended for `--all` mode (model list is fetched from OpenRouter):

```bash
# Use OpenRouter model list (instead of the hardcoded list) for --all mode
npm run generate:all -- --type unit --use-api-models

# Same, but only free models
npm run generate:all -- --type unit --use-api-models --free-only
```

#### Models

**Available free models** (examples): `llama-3.2-3b-free`, `llama-3.1-8b-free`, `qwen-2.5-7b-free`

To see all available models (including free ones):

You can also use full model IDs directly (check availability first):


### Evaluate Generated Tests

After generating tests, evaluate them:

```bash
# Run evaluation
npm run evaluate:tests

# Display beautiful formatted report
npm run show:report

# Fix incorrect import paths in generated tests
npm run fix:imports
```

The evaluation script analyzes generated tests and creates a report. Use `show:report` to display it in a beautiful, colorized format with tables and statistics.

**Note**: If generated tests have incorrect import paths (e.g., `../utils/` instead of `../../utils/` for component tests), use `fix:imports` to automatically correct them.
